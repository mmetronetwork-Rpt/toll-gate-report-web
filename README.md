# Toll Gate Report — Halaman Pembuka (publik)

Halaman onboarding + pembungkus (iframe) untuk aplikasi **Toll Gate Report System PT MMN · PT MAN**.
Repo ini **tidak berisi kode aplikasi, data, atau rahasia** — hanya halaman statis.

## Isi
- `index.html` — slide pembuka dan iframe ke aplikasi
- `assets/` — logo dan foto slide

## Pengaturan
Ubah konstanta `APP_URL` di `index.html` bila URL deploy Apps Script (`.../exec`) berubah.

## Hosting (GitHub Pages, gratis untuk repo publik)
Settings → Pages → Source: branch `main`, folder `/ (root)`.
Setiap commit ke `main` otomatis memperbarui situs dalam beberapa menit.
